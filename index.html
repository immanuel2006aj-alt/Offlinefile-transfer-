Six-digit pairing, direct browser-to-browser transfer, live speed and progress. Designed for large files using streaming chunks and receiver-side disk writing where supported.

Network truth: Pairing uses the PeerJS internet signaling service. File data normally travels directly between devices; if a relay is needed, internet data may be consumed. For best speed, put both devices on the same fast Wi-Fi / hotspot. For reliable multi-GB receiving, use Chrome or Edge on a device that supports saving directly to disk. This is not a guarantee of SHAREit-level speed: Wi-Fi hardware, browser limits and network isolation determine the result.
